# The Jesus Heart Project

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![React 18](https://img.shields.io/badge/Frontend-React-61DAFB?logo=react)](https://reactjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Styling-Tailwind_CSS-38B2AC?logo=tailwind-css)](https://tailwindcss.com/)

A beautiful, high-performance web platform designed to elevate the online presence and outreach of The Jesus Heart Project. 

## 🌟 Overview
This platform serves as the digital front door for the foundation, showcasing its mission, team, and philanthropic efforts across northern Ghana. Designed with modern web standards, it features dynamic carousels, responsive layouts, and seamless user experiences.

## 🏗️ Architecture

### Frontend Layer
- **Framework**: React (Vite)
- **Styling**: Tailwind CSS for rapid, responsive, and robust utility-first design.
- **Routing**: React Router DOM for seamless Single Page Application (SPA) navigation.
- **Animations**: Framer Motion for smooth, professional micro-interactions and transitions.

## 🚀 Development Setup

1. Navigate to the `website` directory:
   ```bash
   cd website
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
